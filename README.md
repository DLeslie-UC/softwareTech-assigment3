


The project was split amongst group members as the task sheet reccomended. The two stages Perform EDA(Stage 1) and Implementation and Deployment(Stage 2)
was chosen for this assignment, Dylan completed stage 1 and Reed completed stage 2. These stages were coded seperately with communication updating on the process
and the code created. The two stages were integrated together by both Dylan and Reed. The README file and Implementation summary was also completed by both Dylan and Reed. 
The group had weekly meetings and collaborated together throughout the project.

After the libraries were imported and tkinter was set up a grid was created to be used in the formatting of the GUI. Functions were then created for selecting and 
displaying the processed images. Widgets and labels were then created. Each widget was used to either display and help the user to select options(via checkboxes)
for the EDA process or to display a processed image and its information. The libraries used in the GUI were customtkinter and PIL, these were used in the formatting 
and design of the widgets, images and checkboxes.
